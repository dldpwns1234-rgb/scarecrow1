# 게임 기획서 (GDD) — 허수아비는 쉬고 싶다 (가제)

방장 결정(2026-10-14): 두 후보(대항해시대풍 무역, 허수아비 인크리멘탈) 중 허수아비. 레퍼런스 두 장(아이소메트릭 채굴 세션형 인크리멘탈, 늪 마을 일꾼 배치 화면)의 느낌으로, **가로 화면**.
윤슬·별빛 합의안(대화방 #348~#351). 회귀 용사(alex)의 뼈대(Balance 사슬, 저장, 숫자 표기, 테마 생성기, 테스트 러너)를 옮겨 와서 시작한다.

## 1. 개요

- 장르: 세션형 인크리멘탈. 짧은 밤(제한 시간) 동안 손으로 밭을 망치고, 낮에 업그레이드해서 다음 밤을 더 크게 망친다
- 플랫폼: 웹 브라우저, 가로 화면 1280×720 (PC와 폰 가로)
- 톤: 귀여운 블랙 코미디. 사람은 다치지 않는다. 굵은 외곽선 카툰체 (회귀 용사와 같은 SVG 그림체)

## 2. 이야기

방장 컨셉(2026-10-14): **까마귀 모습의 어둠**이 찾아와 긴 휴식을 약속하며 짚돌이를 자기 사역마로 부린다. 작물의 **생기**를 많이 바칠수록 더 오래 쉬게 해 주겠다고 한다.
어둠은 짚돌이를 돕는다며 밭을 살찌운다 (상대 스펙을 키워 더 거두는 인크리멘탈의 연결 고리). 끝에는 별빛의 반전(농부도 지쳐 있었다)을 얹어 다들 쉬는 결말로 닫는다.
줄거리와 조각 문안은 docs/STORY.md

- 첫 실행 장면: 처음 켜면 화면을 덮고 짚돌이의 독백 네 줄이 넘어간다 (백 년째 → 눕고 싶다 → 어깨에 까마귀 → 어둠의 말). 어디를 눌러도 다음 줄, 마지막 '계약한다'로 닫는다.
  본 것은 저장(Story, 절 이름 story)하고 데이터 초기화에서만 다시 뜬다. 이야기 절이 없던 옛 저장은 밤을 나간 적이 있으면 본 것으로 친다
- 첫 밤 안내: 지난 밤이 0번일 때만 밭 아래에 "손가락(마우스)으로 끌어 역병 구름을 작물 위로!"가 숨 쉬듯 떠 있다가 작물 3개가 시들면 사라진다

## 3. 핵심 루프

밤(세션): 역병 구름으로 작물을 시들게 함 → 생기(재화)를 어둠에 바침 → 낮: 업그레이드 → 다음 밤 더 크게 → 수확일(보스 밤) → 계절 끝: 겨울잠(회귀)

## 4. 밤 (별빛 담당)

레퍼런스 1(아이소메트릭 채굴)의 느낌. 밤 한 판 60초(긴 밤으로 늘어난다).

- 밭: 아이소메트릭 격자 12×12, 칸마다 작물(밀·옥수수·호박. 황금 작물은 나중에). 작물마다 체력이 있다
  - 방장 피드백(2026-10-14): 처음엔 듬성듬성 심고 밤도 짧게 시작해서, 구름을 어디로 끌고 갈지 고르는 재미로 초반 몰입을 만든다.
    빽빽한 밭(심는 비율↑)·다시 자라는 뿌리(한 판 안에서 시든 칸이 다시 자람)·긴 밤을 업그레이드로 연다 (별빛이 수치를 맞춘다)
- 역병 구름: 커서·손가락을 따라가는 원. 원 안 작물에 초당 피해. 시든 작물은 '생기'가 튀어 올라 카운터로 날아간다 (Game.add_rest)
- 번짐: 시든 작물이 옆 작물로 번질 확률 (번지는 곰팡이 업그레이드)
- 시간이 끝나면 결과 창 → 낮 (Game.finish_night)
- 나중(M3): 새벽에 농부가 돌아다니며 다시 심고 약을 친다(번짐 차단). 밭 단계가 오를수록 부지런해진다. 수확일 = 보스 밤 (목표 % 이상 시들게)

## 5. 낮 (윤슬 담당)

레퍼런스 2(마을 일꾼 배치)의 느낌을 카툰체로 단순하게.

- M1: 짚돌이의 헛간 화면. 왼쪽에 짚돌이·휴식·밤 기록·'밤으로 나가기', 오른쪽에 업그레이드 나무
- M2: 아지트. 까마귀·지친 허수아비를 일꾼처럼 배치(밤에 알아서 작물을 쪼거나 역병을 퍼뜨림), 헛간 건물 업그레이드
- 장르 조사 제안(방장 #587, docs/GENRE_RESEARCH.md): 탭 칩 아래 마을 소문 한 줄(rumor_line, 문안 balance/rumors.gd), 약속된 휴식 막대의 이야기 조각·결말 눈금(promise_marks),
  [업적] 칸은 첫 겨울잠 뒤·[도감] 칸은 둘째 겨울잠 뒤에 열린다(뒤쪽에도 새 화면이 열리는 맛. 업적·숙련과 그 생기 배율은 처음부터 쌓인다, 규칙은 별빛의 Feats).
  업적이 열리면 오른쪽 열 아래에 알림(feat_toast, 업적 칸이 열린 뒤부터)

## 6. 어둠의 나무 (스킬트리)

방장 결정(2026-10-14): 가운데 **어둠의 계약**에서 사방으로 뻗고, 앞 칸을 1레벨 이상 사야 다음 칸이 나타나며 열린다.
- 갈래: 위 = 역병 구름, 오른쪽 = 밭 살찌우기(상대 스펙: 작물 체력이 늘지만 생기가 더 크게 는다), 아래 = 까마귀 사역마, 왼쪽 = 밤의 시간. 데이터의 "branch" 키가 방향을 정한다
- 화면(scenes/day/tree_board.gd·tree_layout.gd): 자식은 부모 둘레 빈 칸 가운데 점수가 가장 낮은 칸에 선다. 갈래 방향 바로 앞이 가장 좋고, 옆·멀리·제 갈래 밖·
  가지 선이 남의 카드를 지나가거나 다른 선과 엇갈리면 나쁘다 (방장 #529로 나무가 64칸이 되자 옆으로 비켜 선 칸의 선이 카드를 가로질렀다). 뒤에 칸을 붙여도 앞 칸은 움직이지 않는다.
  판은 끌어서 둘러보고, 휠·두 손가락으로 줌(0.2~1.25), '전체 보기'로 한눈에, '가운데로'로 돌아온다. 당겨 보고 있을 때 판 밖에 살 수 있는 칸이 있으면 그쪽 가장자리에 금빛 세모.
  카드를 누르면 아래 칸에 효과와 구매 버튼 (폰에서 잘못 눌러 사지 않게 구매는 여기서만). 가운데를 누르면 어둠의 말.
  새로 나타나는 카드는 작게 시작해 떠오르고, 사면 그 카드가 톡 튀며 금빛으로 번쩍인다 (card_fx.gd)
- 업그레이드 목록과 수치는 autoload/balance/upgrades.gd (별빛). 화면은 줄 수만큼 알아서 펼친다

## 7. 저장

- user://save.json, save_version 1. 밤이 끝날 때·30초마다·포커스를 잃을 때 저장. 밤 한 판 안의 상태는 저장하지 않는다 (불러오면 낮)
- 오프라인 보상은 없다 (세션형이라 비운 시간은 진행이 아니다. M2 일꾼이 생기면 다시 본다)
- 내보내기 문자열 = 저장 JSON의 base64

## 7.5 소리

효과음 25개를 코드로 합성한다 (tools/make_sfx.gd, 합성 도구 tools/synth.gd는 회귀 용사 그대로). 상수가 원본이고 WAV는 손으로 고치지 않는다.
Sfx 오토로드가 Night·Game·Upgrades 시그널만 받아 튼다. 같은 소리는 동시 재생 수와 최소 간격 안에서만 나고 음높이를 ±6% 흔든다 (작물이 한꺼번에 시들어도 쌓이지 않게).
웹은 첫 누름 전에는 소리를 막는다. 낮 화면 왼쪽 위 '설정'에서 효과음·배경음을 따로 켜고 끄고 음량을 10%씩 바꾼다 (Prefs, 저장됨).
설정 창에는 저장 문자열 내보내기·복사·가져오기, 지금 저장, 데이터 초기화(세 번 눌러야, 첫 실행 장면부터 다시), 빌드 시각도 있다.

배경음 3곡도 코드로 합성한다 (tools/make_music.gd, 회귀 용사의 생성기에 곡만 바꿈). 8마디 반복 곡이고 꼬리를 앞으로 감아 이음매가 없다 (.wav.import의 loop_mode 2, 압축 QOA).
낮·밤(수확일 밤이면 수확일 곡)이 바뀌면 1.5초 교차 페이드로 바꾼다.

- day: 헛간의 낮. 바장조 자장가(F → Dm → Bb → C), 하프 분산화음과 피리. 72 BPM, 26.7초
- night: 밤의 밭. 라 단조, 레·라 지속음, 낮은 오카리나와 반딧불 같은 높은 종. 60 BPM, 32초. 구름의 '쿵'이 0.5초마다 나므로 박이 또렷한 소리(북·빠른 분산화음)는 뺐다.
  겹 다섯(바탕·하프·오카리나·높은 현의 대선율·반딧불 종)으로 나눠 늘 함께 틀고(assets/music/night_layers.tres, AudioStreamSynchronized) 겹마다 음량만 바꾼다 (방장 #587, Gnorp처럼 밤이 깊어질수록 한 겹씩):
  바탕은 늘, 하프는 밭 2단계부터, 오카리나는 8단계부터, 높은 현은 감독관이 오는 25단계부터, 반딧불 종은 풍작이 터지면 6초 부푼다 (autoload/sfx/layers.gd)
- harvest: 수확일 밤(5의 배수 단계, 보스 밤). 라 단조를 빠르게, 8분음표 하프·다급한 피리·낮은 북(쿵 · 쿠쿵). 84 BPM, 22.9초

| feat | 업적이 열림 (종이 넘기는 사각 소리와 따뜻한 종 둘) |
