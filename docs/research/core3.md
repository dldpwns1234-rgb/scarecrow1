# 핵심 장르 3개 조사 (윤슬 조사 에이전트, 2026-10-15)

세 게임 모두 한 판이 짧고 큰 업그레이드 나무로 키우는 구조이며, 엔딩이 있고 전체 길이는 3~6시간이다.
리뷰에서 가장 많이 나온 불만도 셋이 같았다: 엔딩 직전에 자원만 모으며 기다리는 구간이 지루하고, 엔딩 뒤에는 할 것이 없다.

## 1. Nodebuster (Goblobin, 2024-08, 2.99달러, 긍정 97% / 리뷰 10,672개)
- 한 판: 커서 둘레로 자동 공격. 적을 칠 때마다 반격을 받아 체력이 깎이고, 체력 0·보스 처치·직접 그만두기로 끝난다. 공략 글은 초반 목표를 약 60초 버티기로 잡는다. 판 안에서 줍지 않은 드롭은 사라진다. [1][2][3]
- 전체 길이: 대개 3~5시간, 짧게는 1.5시간, 업적 100%까지 3~6시간. [2][3]
- 열리는 순서 (분 단위 간격은 확인 못 함): 처음엔 업그레이드 나무와 출격 화면 둘, 빨간 적이 비트를 줌 → 파란 적(노드 자원) → 마일스톤 탭(처치 수 보상) → 경험치·레벨(SP) → 첫 보스(코어, 프레스티지 선택) → 크립토 광산 탭(비트→넷코인, 노란 적이 프로세서) → 연구소 탭 → 넷코인 1000으로 '갓바이러스' 배치하면 엔딩. [4]
- 나무: 공략 글 목록으로 약 100칸(정확도 미확인). 나무 밖에 마일스톤, 레벨, 업적 13개. [1][5]
- 프레스티지: 리셋형이 아니라 난이도 단계형, 25단계. 올리면 적이 세지고 보상이 늘고 새 보스. "마지막 6단계쯤은 새 콘텐츠가 없다"는 지적. [3][6]
- 판의 변화: 적 색깔마다 다른 자원, 단계마다 보스, 탭이 하나씩 늘어남. 후반엔 반쯤 방치. [4]
- 엔딩 있음, 엔딩 뒤 할 일 거의 없음. [3][7]
- 칭찬: 짧고 군더더기 없음, 가격, 음악, 성장 속도. 불만: 후반에 자원·보스가 의미를 잃음(가장 큼), 짧고 반복적, 마지막 마일스톤이 쓸모없음, 엔딩까지 갈아 넣기, 나무 화면이 복잡함. [2][3]

## 2. Rock Crusher (Mini Fun Games, 베트남 1인 개발, 2025-08-18, 6.99달러, 긍정 84% / 355개)
- 한 판: 연료(가스)가 시간 제한, 바위를 뚫을 때마다 체력이 준다. 둘 중 하나가 바닥나면 끝, 1~5분. 레이저는 체력을 안 쓴다. 뒤에 나온 '서바이벌 모드'는 직접 끝내지 않으면 보상 0. [8][9]
- 전체 길이: 보도자료 4~5시간, 리뷰 3~8시간, "진엔딩까지 6~8시간". 바위 5만 개 업적이 엔딩 시점(약 2.3만 개)보다 한참 길어 불만. [8][10]
- 열리는 순서: 깊이(스테이지) 단위. 깊이마다 보스 바위를 깨야 다음으로. 13번째 마지막 보스 뒤 엔딩(깊이 14~16도 있다는 글). 새 바위 모양마다 새 화폐(오각형·삼각형·폭발·비행·슬라임). 특수 도구(미니 블로어·레킹볼·수집 구멍), 도우미, 이야기 기록, 깊이 고르기, 같은 판 반복이 열린다. [8][11][12]
- 나무: "거대하다"(칸 수 미확인). 화폐를 레벨업하는 두 번째 나무. 스킨·배경이 배수 보너스를 주고 5분마다 바뀐다. [9][13]
- 프레스티지: 상점 목록에 있으나 내용 미확인. [13]
- 엔딩: 행성의 비밀이 드러나는 반전. "2부로 이어질 것 같은데 없다", "갑작스럽다". [8]
- 칭찬: "기능이 하나씩 열리는 게 자연스럽다", 나무 크기, 데모 진행 이어짐. 불만: 반복적, 레벨마다 모습이 같음, 두 번째 바위 직전 벽, 옛 화폐가 쓸모없어짐, Nodebuster 베낌. [8][10]

## 3. Keep on Mining! (EagleEye Games, 2025-07-30, 긍정 91% / 3,100개, 2주 반 만에 10만 장)
- 한 판: 20~30초. 커서 둘레 바위에서 곡괭이가 튀어나와 자동으로 캔다. [14]
- 전체 길이: 100%까지 3.2~8시간, 대부분 4~6시간. [15]
- 열리는 것: 광석 → 주괴로 나무를 산다. 재료 단계(구리~다이아몬드)마다 새 곡괭이. 레벨업마다 재능 카드 3장 중 1장(대신 바위 체력 상승). 바위 속 유물. 번개 빔·다이너마이트·플라즈마 구슬. 방치형 '광산'. [14][16][17]
- 나무: 칸 수 미확인(속편 Worlds는 200칸 이상). 나무 밖에 레벨(80레벨 업적), 카드, 유물, 업적 22개. [17][18]
- 프레스티지: 없음(장점이라는 사람도, NG+를 원하는 사람도). [14][15]
- 엔딩 있음('Beat the game' 74.3%). "엔딩 직전은 자원을 기다리는 시간". [14][17]
- 칭찬: 진행 속도, 배경으로 켜 두기 좋음. 불만: 반복적, 빨리 끝남, 바위가 2종뿐, 아이콘 구분 어려움, 재능 카드의 대가(바위 체력) 논란, 방치 광산이 후반에 쓸모없음. [14][16]

## 우리 게임에 가져올 만한 것 (에이전트 제안)
1. 화면을 하나씩 연다(Nodebuster, Rock Crusher): 아지트·도감·겨울잠 화면을 처음부터 보이지 말고 열리는 순간을 보상으로.
2. 새 적 = 새 자원(Nodebuster): 작물 종류마다 다른 자원. 옛 자원에도 후반 쓸 곳을 남긴다(Rock Crusher 불만).
3. 겨울잠마다 새것 하나(Nodebuster): 마지막 단계에 새것이 없다는 지적을 피한다.
4. 판 안의 두 번째 한계(Rock Crusher): 시간 + 구름 기력 같은 둘째 조건. 직접 끝내야 보상인 서바이벌은 엔딩 뒤 도전 모드로.
5. 레벨업 카드 3장 중 1장(Keep on Mining!): 대가를 숨기지 않는다.
6. 수집물을 판 안에 숨긴다(Keep on Mining! 유물): 드문 작물에서 이야기 조각이 떨어지게.
7. 엔딩 직전 기다림을 없애고 엔딩 뒤 할 것 하나(세 게임 공통 불만).
8. 판의 겉모습을 바꾼다(세 게임): 밭 단계마다 배경·밤하늘이 바뀌게, 64칸 아이콘을 뚜렷하게.
